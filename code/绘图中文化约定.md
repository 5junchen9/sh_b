# L1 项目绘图中文化约定

适用于 `l1/` 下的探索性图、稳健性图、结果图和论文图。自 2026-08-02 起，所有新建或重绘图表均遵循本约定。

1. 图题、坐标轴、图例、注释、分组名称均使用简体中文；方法编号、变量符号和标准指标名可保留为 `M1`、`C1`、`SOC`、`SOH`、`RMSE` 等。
2. 数值单位使用中文全角括号，例如“循环寿命（循环）”“充电时间（min）”“内阻（Ω）”。变量含义应写为“第一阶段倍率 C1（C 倍率）”，而不是只写英文说明。
3. Python 作图脚本在导入 `matplotlib.pyplot` 前固定使用无界面后端，并设置字体序列：`Microsoft YaHei`、`SimHei`、`DejaVu Sans`；同时设置 `axes.unicode_minus=False`，避免负号和中文缺字。
4. 图中不得把官方分区差异、相关性或模型预测误差表述为因果效应。必要限制直接写在中文图注或图内注释中。
5. 每张图必须保留可追溯来源：脚本、输入数据版本、输出目录及生成时间由相应实验的 `run_summary.json` 或日志记录。原始数据只读。

现有 Q1、Q2、Q3 基线图已按本约定重绘；后续稳健性、Pareto 和论文图沿用同一字体与术语。
