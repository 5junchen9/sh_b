# Q1 最终结果分析：电芯差异与策略级观察性对照

## 1. 方法选择结论

- **正文主线**：M2 策略级聚合比较。<!-- from Q1-D02 -->
- **基础描述**：M1 电芯级寿命分布。<!-- from Q1-D02 -->
- **一致性核对**：M3 Train–Primary 重复策略比较；不得写为稳定策略排序。<!-- from Q1-D02 -->
- **可信度**：中等。<!-- from Q1-D03 -->

选择依据是：M2 有 27 个重复策略组支撑策略级对照；M3 的 Pearson 为 0.9029，但 Spearman 的 95% 区间跨 0，不能支持稳定排序或因果结论。<!-- from Q1-D02 -->

## 2. 结果

### 2.1 电芯级个体差异（M1）

124 枚正式电芯的寿命均值为 801.64 cycle，中位数为 736.50 cycle，四分位数为 498.75 和 946.50 cycle，范围为 148–2237 cycle。2,000 次电芯 bootstrap 给出中位数的 95% 区间 [651.00, 825.00] cycle，说明样本存在明显右偏与个体异质性。

### 2.2 策略级观察性对照（M2）

清洗后的数据中有 68 个策略，其中 27 个策略含不少于两枚电芯，可用于策略内均值、范围和典型案例的描述性比较。重复策略的最低和最高平均寿命分别为 546.5 与 2083.0 cycle；这用于回答“哪些已观测策略整体表现较好”，不表示任何单一倍率的因果效应。

典型重复策略案例为：`3.6C(80%)-3.6C` 的代表电芯寿命为 2160 cycle，`5.4C(60%)-3.6C` 的代表电芯寿命为 559 cycle。二者只用作本数据集内的长、短寿命案例对照。

### 2.3 跨分区一致性（M3）

Train 与 Primary 之间有 19 对完全相同的策略。策略均值的 Pearson 相关为 0.9029（95% 区间 [0.1904, 0.9724]），但 Spearman 为 0.5514（95% 区间 [-0.0231, 0.8791]），平均绝对差为 119.50 cycle。故可说“存在一定线性一致性迹象并伴随数量级约百 cycle 的差异”，不可声称稳定排序、可完全迁移或因果关系。

## 4. 论文可写与不可写

**可写**：数据存在明显电芯级个体差异；在本数据集中，具备重复电芯支撑的策略可作观察性整体对照；策略在不同分区之间有线性一致性迹象但仍存在较大差异。

**不可写**：某倍率或 SOC 切换点“导致”寿命更高；按 M3 得到稳定的策略全排序；将单枚电芯策略写成策略级结论；把 `chargetime` 与理论 `tau_0_80` 混为同一时间量。
