# Q1 图表使用说明（Round 1 描述性结果）

本目录的图都来自 P0 通过后的 124 枚电池。它们回答的是“数据整理后看到了什么”，不是因果检验，也不是最终预测模型。论文正文建议优先使用 **07、08、09、01**；02、03、04、05、06 可放在数据整理或附录。

## 推荐观看顺序

1. 先看 **01**，确定整体寿命的中位数、四分位数和长尾。
2. 再看 **02**，说明官方分区的分布差异，并明确其仅是描述性比较。
3. 看 **07**，从“电池”上升到“策略”，选定长短寿命典型策略。
4. 用 **08** 对照实测充电时间，再用 **03、04** 解释 C1、Q1、C2 和理论时间的差异。
5. 最后用 **09**（正文）或 **06**（附录）说明 SOH 轨迹。

## 使用边界

- `cycle_life_table9` 是官方寿命标签；`SOH_nom` 使用循环容量相对额定容量的描述性定义。
- `early_chargetime_median` 是第 2–20 圈有效充电时间的中位数，单位 min；`tau_0_80_theory_min` 是两阶段恒流公式得到的 0–80% SOC 理论时间，二者不可混写。
- 由于许多策略只有 1 枚电池，策略排名图只把 `n≥2` 的重复策略作为“典型策略”候选；单枚极端值可作为个案，不宜称为稳定策略效应。
- Primary 曾参与策略探索，不能当作完全独立的盲测集。
- 图中关系均为观察性关系；Q2/Q3 的建模和 Q4 的鲁棒性分析完成前，不写“证明”“导致”“最优”等强结论。
