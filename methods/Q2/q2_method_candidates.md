# Q2 候选方法池（Train-only PoC）

目标：以不同 SOC 区间倍率的影响机制、因素排序与交互作用为主，同时保留可供 Q4 使用的设计前寿命代理。正式标签为 41 枚 Train 电芯的 `ln(cycle_life_table9)`，分组单位为 `policy_table9`；历史字段名 `RMSE_log/MAE_log` 均指自然对数尺度。

## M1：主效应 Ridge 基线 `[CANDIDATE - PoC PASS]`

- 数学：以 `C1`、`Q1_percent`、`C2` 线性解释对数寿命，经标准化后做 Ridge 收缩。
- 优点：系数最易解释，是所有交互模型必须超过的透明基线。
- 局限：不能表示不同 SOC 区间倍率之间的交互。
- 评估：policy-group OOF 的 `RMSE_log`、`MAE_log`、系数方向稳定性。
- 预期输出：折外预测表、标准化/原尺度系数表、残差图、策略级误差表。
- 难度：低；PoC：`methods/Q2/poc/m1_main_effect_ridge_poc.py`。
- 可行性数值：41 电芯、40 个策略组，`RMSE_log=0.3842`，`MAE_log=0.2696`。

## M2：二阶交互 Ridge `[CANDIDATE - PoC PASS]`

- 数学：在三项策略变量的主效应基础上加入二阶项和两两交互，再用 Ridge 控制小样本系数膨胀。
- 优点：直接对应题目对 SOC 区间差异与交互作用的要求。
- 局限：自由度增加，系数必须报告不稳定性，不能作因果解释。
- 评估：与 M1 同一 policy-group OOF 的误差、交互项跨折方向、折外高估风险。
- 预期输出：折外预测表、主效应/交互项系数表、交互响应图、策略级误差表。
- 难度：中；PoC：`methods/Q2/poc/m2_interaction_ridge_poc.py`。
- 可行性数值：41 电芯、40 个策略组，`RMSE_log=0.3620`，`MAE_log=0.2550`。

## 比较与边界

| 比较项 | M1 | M2 |
|---|---|---|
| 可解释性 | 高 | 中 |
| 交互作用表达 | 无 | 有 |
| 小样本过拟合风险 | 低 | 中 |
| V2契合度 | 基线 | 高 |
| PoC状态 | 通过 | 通过 |

不纳入本轮的方案：高维树模型/深度模型（41枚 Train 电芯不足以稳定估计）；无约束高阶多项式（会把策略网格稀疏性误写为连续机制）。
