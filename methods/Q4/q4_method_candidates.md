# Q4 方法候选池：受限候选、风险边界与 Pilot 接口

## 1. 子问题摘要

- **目标**：在 Q2/Q3 的冻结边界内权衡充电时间、寿命和 SOH 风险；当前交付限定为候选策略集合、风险边界与 pilot 试验接口，不输出最优新策略或直接可执行处方。
- **问题类型**：优化（模型者已确认输出为 Pareto 权衡方案集）。
- **关键约束**：新策略只能先由 Train 支持域筛选；Primary 不得用于回调；Secondary 已用于一次冻结压力测试，不能重新选模型、窗口或阈值；新策略须经过至少 3 枚物理电芯至 `k=100` 的真实运行才可能升级。
- **数据**：Train 策略组合、Q2-B 代理点预测、Q3 冻结窗口规则及 Q4 已有 dry-run 产物。

## 2. 候选方法

### M1：已有策略的观察性多目标参照  [CANDIDATE — PoC PASS]

- **数学思想**：只对已有 Table 9 策略汇总理论 0–80% 充电时间、已有预测字段与观测证据范围，构成开发期的比较参照；不外推生成新策略。
- **优点**：完全立足已有实验策略；可作为图表和 pilot 代表点选择的参照基线。
- **局限**：不能扩展到未试验连续策略；当前已有 Primary 暴露，且外部证据不足以称为正式最优 Pareto。
- **预期输出**：已有策略比较表、开发期参照图、证据范围说明。
- **评价口径**：只报告已有策略与证据范围；不产生“推荐最优”。
- **实现难度**：低。
- **PoC 脚本**：`methods/Q4/poc/m1_observed_policy_reference_poc.py`。
- **可行性结果**：`60` 个已有策略记录、`84` 枚电芯观察，开发期 Pareto 标记 `4` 条；该标记不是正式 Pareto。

### M2：Train-only 双空间支持域筛选与 k=100 Pilot 闭环  [CANDIDATE — PoC PASS]

- **数学思想**：在离散策略网格上同时计算 raw 参数空间和 SOC 暴露空间的 5-NN 支持；以 Train barcode bootstrap 支持率筛除外插点，保留 `Q2_provisional`，再以最少 3 条代表策略 × 3 枚物理电芯的 `k=100` 真实运行组成闭环。
- **优点**：将“模型可计算”与“已验证有效”分开；能给出风险受控的候选和明确升级门槛；完全符合现有 Q2/Q3 冻结边界。
- **局限**：候选仍不是有效或最优策略；依赖未来 pilot 试验，当前不能输出最终 Pareto 或寿命下界。
- **预期输出**：支持域阈值、`Q2_provisional` 名单、三类代表点、9 槽位 pilot 登记表与升级规则。
- **评价口径**：双空间支持均通过、bootstrap 支持率不低于 80%、新策略完成 `k=100` 真实确认后才可升级。
- **实现难度**：中。
- **PoC 脚本**：`methods/Q4/poc/m2_train_support_pilot_poc.py`。
- **可行性结果**：Train-only 流程得到 `1775` 条 `Q2_provisional`，最小 bootstrap 支持率 `0.800`；raw 5-NN 距离范围为 `[0.288, 1.069]`。

## 3. 明确拒绝的方向

| 方向 | 拒绝原因 |
|---|---|
| 直接用 P3 或受限提升树的点预测在连续空间搜索“最优”处方 | Q2 的 P3 在 Secondary 没有获得升级支持，且点预测不是保守寿命下界。 |
| 在参数 min/max 盒内任意加密网格后选最优点 | 参数范围内不等于处于 Train 支持域，易产生不可验证外插。 |
| 用 Secondary 结果回调距离阈值、窗口、模型或代表点 | 会把一次最终压力测试变为调参数据，破坏外部检验意义。 |

## 4. 基线

- **基线**：M1 已有策略观察性参照。
- **原因**：不产生新策略、完全可追溯；M2 的候选筛选必须相对这个保守参照来解释，而不能声称替代真实实验。

## 5. 选择待裁决（学习模式）

当前为 `learning` 模式，人工模型者完成权衡前不展示 AI 的优先建议。请在
`methods/Q4/decisions/method-selector_modeler_decision.md` 中选择：

- 仅以 M1 作为已有策略的观察性回答；或
- 以 M2 作为 Q4 的正式交付框架，并保留 M1 为参照；或
- 指定另一种有明确边界的组合。

无论选择哪项，当前证据都不允许输出“最优新充电策略”。

## 6. 比较矩阵

| 维度 | M1 已有策略参照 | M2 支持域 + Pilot 闭环 |
|---|---|---|
| 新策略生成 | 否 | 仅 provisional 候选 |
| 支持域控制 | 不适用 | 双空间 5-NN + bootstrap |
| 真实验证接口 | 无 | k=100、每点至少 3 枚电芯 |
| 可输出最优策略 | 否 | 否 |
| 可解释性 | 高 | 高 |
| 工程可操作性 | 中 | 高 |
