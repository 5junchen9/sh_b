# L1 原始 MAT 深层循环审计报告

## 结论

原始 `cycles.t/Qc/I/V/T/Qd` 已完成全量只读扫描。正式名册内 100,501 个原始循环中，100,243 个可用于曲线特征；其余 258 个循环仍保留在源数据和审计表中，只通过字段—循环掩码排除出曲线特征计算。

## 检查范围与规则

扫描三份 MAT 的全部 114,738 个循环，并为每个循环检查六个数组：`t`、`Qc`、`I`、`V`、`T`、`Qd`。

| 检查 | 规则 |
|---|---|
| 数组长度 | 六字段长度必须一致 |
| 空数组 | 六字段同时为空时标记为不可用于曲线特征 |
| 非有限值 | 任一字段含 NaN 或 Inf 即标记 |
| 时间 | `t` 不得为负，且不得出现相邻降序 |
| 容量 | `Qc/Qd` 不得为负 |
| 电流 | `abs(I)` 不得超过 12 A；依据文献最大 8 C、额定容量约 1.1 Ah（8.8 A）设置留有余量的保守阈值 |
| 电压 | `V` 必须位于 0–5 V 的保守物理范围 |
| 温度 | `T` 必须位于 −40–100 °C 的保守物理范围 |

不对 `I` 设正负方向边界，因为充/放电阶段的电流符号不同；仅检查其绝对幅值上界。

## 使用方式

曲线、增量容量或时间积分特征只能使用：

```text
in_official_roster == 1 AND usable_for_curve_features == 1
```

不得对 `t` 单独排序；这样会破坏其与 `I/V/T/Qc/Qd` 的逐点同步。若模型必须使用被掩码的循环，应单独报告“掩码后窗口可用性”，不得静默回填。
