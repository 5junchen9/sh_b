# L1 数据字典与使用边界

来源：`B.docx` 题面、`1710560890-r2I8.pdf` 的 Supplementary Table 9/补充图 2，以及三个只读 MAT 文件的结构核验。

## 正式分析单位

一行代表一个唯一物理电芯（以 `barcode` 为键）。正式样本名册为论文 Supplementary Table 9 的 124 个条码；同条码的跨批次观测只能作为同一电芯的连续片段或重复证据，不能拆成独立样本。

## 字段

| 字段 | 含义 | 单位/类型 | 正式使用规则 |
|---|---|---|---|
| `barcode` | 电芯唯一条码 | 文本 | 大写规范化后作为唯一键 |
| `dataset` | 论文数据分区 | 分类 | 仅取论文 Table 9 的 `Train`、`Prim. Test`、`Sec. test` |
| `batch_date` | 实验批次起始日期 | 日期 | 仅取论文 Table 9 |
| `cycle_life` | 达到论文定义寿命阈值的循环寿命 | cycle | 仅取论文 Table 9，禁止用本地同名字段替代 |
| `C1` | 第一段充电倍率 | C-rate | 由论文策略 `C1(Q1%)-C2` 解析 |
| `Q1` | 两段充电切换 SOC | % SOC | 由论文策略解析 |
| `C2` | 第二段充电倍率 | C-rate | 由论文策略解析 |
| `QDischarge` | 每循环放电容量汇总 | Ah（待题面/原始实验说明最终确认） | 可作 SOH/容量衰减候选量；不得与寿命标签混用 |
| `QCharge` | 每循环充电容量汇总 | Ah（待确认） | 同上 |
| `IR` | 每循环内阻汇总 | Ω（题面/用户确认；测量时点仍未说明） | 可用作特征；不把它等同于 EIS 谱阻抗或据此设置外部安全阈值 |
| `Tmax`、`Tavg`、`Tmin` | 每循环温度汇总 | °C（待原始说明确认） | 可用作特征，注意批次混杂 |
| `chargetime` | 每循环充电时间汇总 | min（题面/用户确认；起止点及是否覆盖完整 CV 阶段仍待说明） | 可作为分钟量纲的实测时间候选；仍须与理论 `tau_0_80` 分列，并在 Train 中验证校准关系 |
| `Vdlin` | 线性化放电电压采样序列 | V（1000 点/记录） | 可用于早期特征；与其所属条码/循环严格绑定 |
| `cycles` | 原始循环嵌套结构 | MAT struct | 仅按字段—循环掩码处理，不能因局部异常整电芯静默删除 |

## 明确禁止

1. 不以 `data_*.xlsx` 中的 `cycle_life` 或 `policy_readable` 作为正式标签。
2. 不将 5 个跨批次重复条码拆入不同训练/测试集合。
3. 不把论文名册外的 11 个条码纳入主分析。
4. 预测任务的任何特征、标准化、插值或筛选参数仅能使用预测时点以前的循环，且仅在训练集拟合。

## 已确认充电协议

`B.docx` 题面说明快充策略由 0--80% SOC 的两段恒流组成：先以 `C1` 从 0% 充至 `Q1`，再以 `C2` 从 `Q1` 充至 80%；80% 后对所有电芯统一采用 1C 恒流--恒压充至满电，电流降至 C/50 时结束。**3.6 V 上限不是题面条件**：它来自题目引用的 Severson 等原始研究 `1710560890-r2I8.pdf` 补充图 2，其中说明电芯在 80% SOC 后以 1C 充至 3.6 V，再在 3.6 V 恒压充电，且该上限受制造商限制。该统一尾段不属于策略变量，理论 `tau_0_80` 也不是完整 0--100% 充电时间。
