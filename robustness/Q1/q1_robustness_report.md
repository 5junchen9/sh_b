# Q1 描述性结论的稳健性报告

## 1. 计算范围

本报告不拟合预测或因果模型。它仅对 Q1 的两类描述性结论进行重抽样：全体 124 枚官方电芯的寿命分布，以及 19 个 Train–Primary 重复策略的跨分区一致性。

### 1.1 已完成的可复现性与稳健性检查

1. ✓ **电芯单位重抽样**：寿命分布采用 2,000 次以物理条码为单位的有放回 bootstrap，未把同一电芯的循环记录误作独立样本；结果见 `tables/q1_lifetime_distribution_bootstrap.csv`。
2. ✓ **策略单位重抽样**：跨分区一致性采用 2,000 次以 19 个重复 `policy_table9` 为单位的有放回 bootstrap，避免策略内多个电芯造成重复加权；结果见 `tables/q1_repeated_policy_agreement_bootstrap.csv`。
3. ✓ **中心与离散统计同时核对**：均值、中位数、第一/第三四分位数均给出点估计和 95% 区间，未以单一均值替代右偏寿命分布。
4. ✓ **线性与秩相关同时报告**：Pearson 与 Spearman 同时计算；Spearman 区间跨 0 的事实被明确保留，未将线性一致性错误升级为稳定的策略排序结论。
5. ✓ **数据使用边界核对**：Q1 的 124 枚全体分布只用于描述数据范围；Primary/Secondary 未被用于 Q2/Q3 的模型拟合、调参或模型选择。
6. ✓ **结论边界核对**：报告明确区分“样本内重抽样不确定性”与“未来批次覆盖”，并禁止把重复策略的相关性写成因果效应或个体寿命的充分决定因素。

## 2. 寿命分布

以电芯为单位有放回 bootstrap 2,000 次：

| 统计量 | 点估计（cycle） | 95% 区间（cycle） |
|---|---:|---:|
| 平均寿命 | 801.64 | [739.96, 869.59] |
| 中位寿命 | 736.50 | [651.00, 825.00] |
| 第一四分位数 | 498.75 | [482.99, 534.02] |
| 第三四分位数 | 946.50 | [865.50, 1048.00] |

分布右偏、存在长寿命尾部的描述不依赖单个电芯；但这些区间反映样本内不确定性，不代表未来批次的覆盖区间。

## 3. 重复策略的一致性

以策略组为单位有放回 bootstrap 2,000 次：

| 指标 | 点估计 | 95% 区间 |
|---|---:|---:|
| Pearson 相关 | 0.9029 | [0.1904, 0.9724] |
| Spearman 相关 | 0.5514 | [-0.0231, 0.8791] |
| 平均绝对寿命差 | 119.50 cycle | [69.00, 175.01] cycle |

Pearson 的点估计较高，但 Spearman 区间可跨 0，说明只有 19 个策略且策略内样本数不均时，**不能**将“策略排序稳定”写成强结论。较稳妥的表述是：重复策略在两个分区间呈现线性一致性的迹象，同时仍存在数量级约百循环的跨分区差异；策略不能完全决定个体寿命。

## 4. 结论边界

- 本报告不区分策略效应与批次效应，不能用于因果归因。
- 全体分布混合了 Train、Primary、Secondary；它用于认识数据而非模型调参。
- Primary 与 Secondary 未被用于 Q2/Q3 的拟合或本报告之外的模型选择。
